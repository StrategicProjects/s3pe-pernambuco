Os dados da plataforma, em uma linha.

O s3.pe.gov.br é o armazenamento de objetos S3 (um servidor Garage) da plataforma Condepe/Fidem. Esta página mostra como consumi-lo com o pacote s3pe em R, Python, Rust, Go e na linha de comando.

Credenciais

Três variáveis de ambiente. Não há leitura anônima: cada projeto tem um bucket e uma chave próprios, pedidos a quem administra a plataforma. A chave de leitura basta para consumir; a de escrita é do ETL que publica.

~/.Renviron (R) · .env ou export (shell)

S3PE_ENDPOINT=https://s3.pe.gov.br
AWS_ACCESS_KEY_ID=GK...
AWS_SECRET_ACCESS_KEY=...
# S3PE_BUCKET=iaempe             opcional: chaves sem s3://
# dentro do servidor da plataforma:
# S3PE_ENDPOINT=http://127.0.0.1:9003

Reinicie a sessão do R depois de editar o ~/.Renviron. Nunca deixe a chave em script, em .Rprofile versionado ou em repositório. A região de assinatura é a padrão, us-east-1.

🔑

Chaves começam com GK

São chaves do Garage. Uma chave por projeto, com leitura, ou leitura e escrita, no bucket do projeto. s3pe buckets mostra o que a sua chave enxerga.

🧭

Rede

Da internet e das máquinas de desenvolvimento funciona direto. Redes internas do Estado podem exigir liberação de firewall para s3.pe.gov.br:443; o sintoma é timeout, não erro de credencial.

Buckets publicados

Regra do manifesto: o metadata.json ou manifest.json é sempre o último objeto a subir. Se a data dele é T, tudo o que ele lista já estava no bucket em T. Leia-o primeiro, use a data como versão do lote e a lista dele em vez de listar o bucket.

BucketLayoutMarcador de lote
iaempedados/: os JSON e GeoJSON do dashboard do IAEM-PE (séries, ranking, municípios)

etl/manifest.json
horizonte-fiscalseries/estado/<codigo>.csv.gz (Estado e macro), series/municipios/<ibge>/<codigo>.csv.gz
previsoes/<ibge>/<codigo>/ultima.json e <AAAA-MM-DD>.json		manifest.json (gerado_em, lista de séries)
sdsbucket do projeto SDS, criado em 2026-10-24 para testes com o s3pe; sem layout definido ainda. Chaves sds (leitura e escrita) e sds-leitura.a definir

Séries do Horizonte Fiscal: CSV gzip com competencia,valor,origem,previa, uma linha por mês. Códigos (icms, fpe, fpm, ipca, …) e unidades estão no manifesto. O código IBGE do Estado é 26; municípios têm 7 dígitos (Recife, 2611606).

Exemplos

O formato vem da extensão: JSON vira lista/dict, CSV e Parquet viram tibble/DataFrame, GeoJSON vira sf no R. Com o bucket padrão definido, as chaves ficam curtas; para um segundo bucket, use a URL s3://bucket/chave.

R · install.packages("s3pe")

library(s3pe)
use_endpoint("https://s3.pe.gov.br")
use_bucket("iaempe")

meta       <- read_s3("dados/metadata.json")
series     <- read_s3("dados/series.json")
municipios <- read_s3("dados/pe_municipios.geojson")  # sf
painel     <- read_s3("etl/painel_iaempe.parquet")    # tibble
list_s3("dados/")

# Horizonte Fiscal
manifest <- read_s3("s3://horizonte-fiscal/manifest.json")
icms <- read_s3("s3://horizonte-fiscal/series/estado/icms.csv.gz")
fpm  <- read_s3("s3://horizonte-fiscal/series/municipios/2611606/fpm.csv.gz")
prev <- read_s3("s3://horizonte-fiscal/previsoes/26/icms/ultima.json")

# escrita: chave com permissão, num prefixo seu
write_s3(painel, "nota_tecnica/painel.parquet")
upload_s3("figura1.png", "nota_tecnica/")

Python · pip install "s3pe[pandas]"

import s3pe

s3pe.configure(endpoint="https://s3.pe.gov.br", bucket="iaempe")
meta   = s3pe.read_s3("dados/metadata.json")        # dict
painel = s3pe.read_s3("etl/painel_iaempe.parquet")  # DataFrame
icms   = s3pe.read_s3("s3://horizonte-fiscal/series/estado/icms.csv.gz")
prev   = s3pe.read_s3("s3://horizonte-fiscal/previsoes/26/icms/ultima.json")

s3pe.write_s3(painel, "nota_tecnica/painel.csv")
s3pe.download_s3("dados/pe_municipios.geojson", "pe.geojson")
for o in s3pe.list_s3("dados/"):
    print(o.size, o.key)

Rust · cargo add s3pe

let s3 = s3pe::Client::builder()
    .endpoint("https://s3.pe.gov.br")   // ou S3PE_ENDPOINT
    .bucket("iaempe")
    .build()?;                          // credenciais do ambiente
let meta = s3.read("dados/metadata.json")?;
s3.upload("painel.parquet", "etl/painel_iaempe.parquet", None)?;
for o in s3.list("s3://horizonte-fiscal/series/estado/")? {
    println!("{:>8} {}", o.size, o.key);
}

Publicar um lote · sync com manifesto por último (R e shell)

sync_up_s3("output/painel", "s3://iaempe/etl/", last = "manifest.json")
✔ sync output/painel → s3://iaempe/etl/: 3 uploaded, 28 unchanged, 0 deleted (2.1 s)
$ s3pe sync output/painel s3://iaempe/etl/ --last manifest.json
$ s3pe sync s3://iaempe/dados/ ./dados-local      # espelho local do lote
# link temporário para quem não tem credencial
presign_s3("etl/painel_iaempe.parquet", expires = 3600)

$ s3pe buckets

Problemas conhecidos

403 SignatureDoesNotMatch

Credencial errada no ambiente (a chave começa com GK; confira com Sys.getenv("AWS_ACCESS_KEY_ID")) ou região diferente de us-east-1.

403 AccessDenied

A chave não tem permissão para este bucket, ou é só de leitura e você tentou gravar.

Timeout

A máquina não alcança s3.pe.gov.br:443: rede interna sem liberação de firewall, ou sem saída para a internet.

ConfigError: no endpoint

Falta S3PE_ENDPOINT (ou use_endpoint(), configure(endpoint=)): o s3pe não assume nenhum servidor.

O lote do bucket pode estar um dia atrás da fonte: os espelhos rodam de madrugada. Compare a data do manifesto antes de concluir que algo falta.
